## Introduction

This is the source code for [Sascha Willems - How to Vulkan in 2026](https://www.howtovulkan.com/).

This tutorial uses Vulkan 1.3 and the C-style Vulkan header. If you prefer C++ RAII, see [Vulkan-Hpp / RAII_Samples](https://github.com/KhronosGroup/Vulkan-Hpp/tree/main/RAII_Samples).

## Compile

This project uses:

- CMake
- Ninja
- Clang / Clang++
- Vulkan SDK

### Windows Powershell

Install dependencies with [Scoop](https://scoop.sh/):

```powershell
# Install Scoop package manager
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression

scoop install llvm ninja cmake
```

Then run:

```powershell
.\run.ps1
```

```PowerShell
cmake -B build -G Ninja `
  -DCMAKE_C_COMPILER=clang `
  -DCMAKE_CXX_COMPILER=clang++

cmake --build build

.\build\bin\HowToVulkan.exe
```

### Linux / macOS / WSL / MSYS2

I'm sure you know what to do. Use `run.sh` to make your life easier.
